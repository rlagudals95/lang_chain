# langchain

## **Architecture**
![image](https://github.com/user-attachments/assets/f0acb5ec-1619-4bf8-9abd-91683c39b571)


- **LangChain**:
    - **LangChain**은 여러 개의 **LLM (Large Language Model)**을 연결하여 복잡한 작업을 처리하는 **워크플로우**를 만드는 라이브러리입니다. 여러 LLM을 **순차적 또는 병렬**로 호출하여 하나의 작업을 수행할 수 있습니다.
    - **Chain**은 여러 개의 **LLM 호출**, **데이터 처리**, **외부 API 호출** 등 여러 단계를 **연결하여** 하나의 프로세스를 구축하는 구조입니다.
- **LLM 호출**:
    - **LLM**은 **GPT, Claude, Sonet** 등과 같은 자연어 처리 모델로, 사용자의 질문에 대한 답변을 생성하거나 특정 태스크를 수행합니다.
    - **Chain 내에서 LLM 호출**은 **정보 추출, 추가 정보 요청, 답변 생성** 등을 순차적으로 이어서 처리하는 방식으로 작동합니다.
- **정보 추출 및 추가 정보 단계**:
    - **정보 추출** 단계에서는 사용자 질문에 필요한 정보를 **벡터 DB**, **API**, **스크래핑** 등을 통해 **검색하거나 추출**합니다.
    - **추가 정보** 단계에서는 필요한 데이터를 **조합**하거나 **변형**하여 최종적인 답변을 생성하기 위한 기초 자료를 준비합니다.
- **벡터 DB 활용**:
    - 벡터 DB는 **대규모 텍스트나 고차원 데이터**에 대한 효율적인 **유사도 검색**을 제공하며, **LLM**과 결합하여 **정확한 정보 검색**을 돕습니다. 예를 들어, 질문을 벡터화하고, 벡터 DB에서 유사한 데이터를 **검색**하여 최종 답변을 도출합니다.
- **추가 정보 제공 및 답변 생성**:
    - 마지막 단계에서는 **정보를 정리**하고, **LLM**을 사용하여 **자연어로 결과를 생성**합니다. 이 때, 필요한 데이터는 **검색**하거나 **질의**로부터 유도된 정보를 바탕으로 처리됩니다.


## **Agent**  
<img width="1054" alt="image" src="https://github.com/user-attachments/assets/8d95baea-ff74-4359-b0bd-d1442a919b81" />


LangChain의 **"Agent"**(에이전트)는 주어진 목표를 달성하기 위해 도구(예: 검색, 계산, API 호출 등)를 활용하여 동적으로 의사결정을 내리는 시스템입니다.

### 🔹 **Agent의 핵심 개념**

1. **Action(행동)**: 입력을 분석한 후, 어떤 도구를 사용할지 결정
2. **Tool(도구)**: 외부 API, DB, 계산기 등 실제 작업을 수행하는 기능
3. **LLM(언어 모델)**: 주어진 문제를 이해하고 적절한 Action을 선택
4. **Prompting(프롬프트)**: LLM이 올바른 결정을 내리도록 가이드

### 🔹 **Agent의 작동 방식**

1. 사용자의 질문을 입력받음
2. LLM이 질문을 분석하고 적절한 도구를 선택
3. 도구를 사용하여 필요한 정보를 얻음
4. 결과를 종합하여 최종 응답을 반환

### 🔹 **Agent의 종류**

- **ReAct (Reason + Act)**: 한 번에 한 단계씩 생각하면서 행동 (반복 루프 가능)
- **Zero-shot ReAct**: 한 번의 프롬프트로 결정
- **Self-ask with Search**: 필요한 경우 검색을 통해 추가 정보를 얻음
